Sega Saturn game Astal (Sega CS2, US MK-81019 V1.003, 1995; SH-2 code, Hitachi SHC or GNU; SGL/SBL library calls likely). Research only. Game: hand-drawn 2D platformer; Astal walks, jumps, punches, lifts and throws enemies and rocks, slams the ground, blows wind; the bird companion Leda is commanded by button to attack, fetch items or heal; boss fights per round, VDP2 multi-layer parallax backgrounds, VDP1 large scaled sprites, CPK movies, PCM/sequence sound through a 68000 driver (AAASDDRV.TSK). The boot program A0SYS.BIN is loaded at 0x060b0000 and stays resident; it loads round overlays R<nn>.BIN (R11..R97, APT/BPT title/pause) at 0x06002000 and sprite/scroll data files. Focus names on the file loader, overlay dispatch, player state and input, Leda commands, enemy/object lists, collision, camera scroll, VDP1 sprite command building, VDP2 layer setup, sound commands.

Task: name functions from the Ghidra decompile. FILE holds the decompile of a slice of the functions of {OVL}. Name EVERY function in FILE whose name is still FUN_xxxxxxxx (skip ones that already have a name).

Evidence to use: strings, called functions (names given by earlier slices), Saturn hardware registers, how the function uses its arguments.
